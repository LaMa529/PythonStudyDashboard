# StudyDashboard

## 🎓 Study Dashboard (Python OOP Project)
An overview for students to keep track of their studies. This includes displaying a grade point average, study progress, an expected graduation date, an overview of modules with links, and other features.


## ✨ Features
- Predicted end of studies
- Current grade point average
- Study progress in percent
- What-if calculator
- Overview of modules “in progress” or “registered”
- Overview of all stored modules
- URL links to desired pages
- Create, edit, and filter modules
- Dark mode


## 🛠️ Requirements
Python: Version 3.10 or newer (Tested with 3.12+)

Pip: Python package manager (usually included with Python)

Operating System: Windows 10/11, macOS, or any modern Linux distribution


## 🚀 Installation Guide
### Schritt 1: Herunterladen und Entpacken
1.	Klicken Sie auf der Webseite auf den grünen Button "<> Code" und wählen Sie "Download ZIP".
2.	Wichtig: Entpacken (Extrahieren) Sie die heruntergeladene ZIP-Datei vollständig an einem beliebigen Ort auf Ihrem PC (z. B. auf dem Desktop). Starten Sie die Dateien nicht direkt aus der komprimierten Ordneransicht heraus.

### Schritt 2: Automatisiertes Starten
#### Windows
-	Führen Sie einfach einen Doppelklick auf die Datei run_windows.bat aus. Es öffnet sich kurz ein Konsolenfenster für die Installation, danach startet das Dashboard.

#### macOS/Linux
-	Öffnen Sie ein Terminal-Fenster in dem entpackten Ordner und führen Sie diese Befehle aus: chmod +x run_unix.sh ./run_unix.sh
